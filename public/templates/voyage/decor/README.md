# Voyage decor artwork

Transparent PNGs used as decorative artwork by the Voyage template
(`src/templates/voyage/components/decor.tsx`). Drop files with these exact
names into this directory; any file that is missing falls back to the
template's built-in line-art SVG, so partial sets are fine.

| File                 | Artwork                                        | Used at                                   |
| -------------------- | ---------------------------------------------- | ----------------------------------------- |
| `floral-spray.png`   | Tall rose/peony spray                          | About Us & Destination side accents       |
| `floral-spray-2.png` | Second tall spray variant                      | Wedding Weekend & RSVP side accents       |
| `floral-branch.png`  | Delicate small-bloom branch                    | Travel & Questions side accent            |
| `floral-corner.png`  | Corner rose cluster                            | Section/footer corners                    |
| `floral-corner-2.png`| Arched top-corner cluster                      | Wedding party / About Us corners          |
| `church-seal.png`    | Church facade with floral flourish beneath     | Hero "Let's Celebrate" card seal          |
| `church.png`         | Church front with trees                        | Timeline "wedding day" vignette           |
| `hacienda.png`       | Wide hacienda courtyard sketch                 | RSVP band illustration                    |
| `coffee.png`         | Coffee cups vignette                           | Timeline "first hello" vignette           |
| `mountains.png`      | Mountain landscape vignette                    | Timeline "first trip" vignette            |
| `ring-box.png`       | Ring box vignette                              | Timeline "proposal" vignette              |

Keep backgrounds transparent and trim excess whitespace so the layout spacing
stays predictable. ~1000px on the long edge is plenty.
